# Answers

The puzzles in order, from the top of the descent to the bottom. Answers are not case-sensitive. Extra spaces, punctuation at the start or end, and a leading "a", "an" or "the" are ignored, so ` The  Moon! ` counts as `moon`.

Where a puzzle has several versions, one is picked at random each time the page loads.

Every slug was generated with `crypto.randomUUID()`.

## 1. Word ladder

Type the middle words into the answer box, separated by spaces, for example `dear deer`. Including the start and goal words is also fine. Each ladder below is the shortest path, and any other valid path is also accepted.

| Start | Answer to type | Goal |
|---|---|---|
| TEAR | dear deer | DEEP |
| LUCK | lack lark | DARK |
| MALL | mill milk silk | SINK |
| BULL | bill bile tile | TIDE |
| FULL | fall ball bail | BAIT |

## 3. Caesar cipher

Every letter is shifted 3 places forward, so decode by moving each letter 3 back (D → A, E → B, and so on).

| Encoded | Answer |
|---|---|
| eoreilvk | blobfish |
| frudo | coral |
| eoxh zkdoh | blue whale |
| elnlql erwwrp | bikini bottom |
| zdwhu | water |
